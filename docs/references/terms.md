# 용어 풀이

## 원본 앱

기존 `chatbot_rag` 프로젝트다. 튜토리얼에서는 `<original_app_root>`라고 부른다.

## 원본형 앱

원본 앱과 같은 구조, API, 웹 화면, 관광 상담 흐름을 가진 `project_template` 산출물이다.

## RAG

검색한 문서 근거를 프롬프트에 넣고 답변을 생성하는 방식이다. 이 튜토리얼에서는 문서 로딩, 분할, 임베딩, 벡터 검색, 프롬프트 구성, 답변 생성 흐름으로 나눈다.

## TourAPI

한국관광공사 관광 데이터 API다. 지역 코드, 관광지, 무장애 정보, 캐시 흐름을 설명할 때 사용한다.

## 사용자 표면

사용자가 직접 보는 웹 화면과 API 응답 문구다. 튜토리얼 설명이나 내부 구현 용어를 넣지 않는다.
