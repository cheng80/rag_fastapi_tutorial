# Tutorial Documentation

이 폴더는 튜토리얼북 Markdown 원고와 참고 자료를 보관한다.

## 하위 폴더

- `chapters/`: 장별 본문
- `references/`: 용어, 명령어, 오류 해결, production 프로젝트 매핑

## 작성 규칙

각 장은 초급 개발자가 그대로 따라 할 수 있도록 다음 순서를 유지한다.

1. 이번 장에서 만들 것
2. 왜 필요한가
3. 최종 폴더 상태
4. 새로 만들 파일
5. 코드 전체
6. 코드 흐름 설명
7. 실행 명령
8. 성공 기준
9. 검증 노트북
10. 자주 나는 오류와 해결
11. 다음 장으로 넘어가기 전 체크리스트
