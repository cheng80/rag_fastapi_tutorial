5현재 운영 정책

근거 없는 정보 생성 금지

공공데이터나 예비 카드에 없는 접근성 정보는 추측하지 않고 확인 필요로 남긴다.

운영 검색은 벡터 검색

BM25, AutoRAG는 오프라인 비교 도구다. 실제 서비스 검색은 bge-m3 + top_k=40 유지.

Live 우선 + 저장 자료 안전망

live_update는 TourAPI를 먼저 확인하고, 지연·실패 시 캐시/RAG/fallback으로 즉시 응답한다.

관계 호칭만으로 나이 추정 금지

아빠, 어머니, 부모님만 보고 고령자 조건을 만들지 않는다.

시군구 자동 확장 금지

좁은 지역을 말하면 타 지역을 섞지 않는다. 확장 요청이 명확할 때만 넓힌다.

LLM 보조는 선택 사항

후보에 없는 장소나 접근성 정보를 만들 수 없고, 기본값은 reasoning assist OFF다.
