# Project Template

이 폴더는 튜토리얼을 따라 만들 최종 예제 프로젝트 구조를 설계하는 곳이다.

실제 튜토리얼 본문에서는 학습자가 빈 폴더에서 아래 구조를 직접 만든다.

```text
rag_fastapi_tutorial_app/
├─ app/
├─ data/
├─ frontend/
├─ notebooks/
├─ scripts/
├─ tests/
├─ prompts/
├─ .env.example
├─ requirements.txt
└─ README.md
```

이 폴더는 production repo 복사본이 아니다. 교육용으로 필요한 최소 구조와 코드만 별도로 정의한다.
